# 경북 자원 지도

4학년 사회 공개수업(2026-10-21)에서 아이들이 경북 22개 시군의 자원을 조사해 지도에 올리고, 자원끼리 화살표로 잇고, TAG 피드백과 AI 챗봇(제미나이)으로 일반화 문장을 쓰는 웹앱입니다.

- 학생용 주소: https://jcteacher7.github.io/gyeongbuk-resource-map/ (아래 3번을 마친 뒤 열립니다)
- 이 저장소는 공개로 쓸 예정이라 아이들 실명과 비밀 키는 넣지 않습니다.

## 지금 되는 것 (만드는 순서 1번: 지도)

- 들어가기: 모둠 → 이름 고르기 (명단은 아직 시험용 가짜 이름. 선생님 화면은 2번 단계에서 만듭니다)
- 우리 지도: 정확한 경북 22개 시군 지도, [+] [−] [처음 크기], "크게 보기", 한 손가락으로 밀어 옮기기
- 자원 카드: 환경(자연/인문)과 이유 → 자원 이름과 많아요/적어요 → 링크와 사진 한 장
- 화살표 잇기: [화살표 잇기] → 출발 자원 → 도착 자원 → 교류 방식, 생활 변화 두 줄
- 화살표를 누르면 두 자원 사진과 "환경 → 교류 → 생활 변화" 세 걸음이 팝업으로 열립니다
- 고치기는 같은 모둠 누구나, 지우기는 올린 사람만
- 인터넷이 끊겨도 이 태블릿에 먼저 보관하고, 연결되면 저절로 보냅니다(오른쪽 위 점: 초록=공유 중, 주황=아직 못 보냄, 회색=이 기기에만)
- TAG, AI 챗봇 화면은 잠겨 있습니다(2번 단계에서 만듭니다)

## 선생님이 직접 해야 하는 일

### 1. Supabase에 저장 공간 만들기 (한 번만, 5분)

1. https://supabase.com 에 로그인하고, 기존 앱에서 쓰던 프로젝트를 누릅니다.
2. 왼쪽 메뉴에서 **SQL Editor**를 누릅니다.
3. 위쪽의 **+** (New query)를 누릅니다.
4. 이 저장소의 `supabase/schema.sql` 파일 내용을 전부 복사해 빈 칸에 붙여넣습니다.
5. 오른쪽 아래 **Run**을 누릅니다.
6. 아래 결과 칸에 "gb_entries 표와 gb-photos 사진 공간이 준비되었습니다"가 보이면 끝입니다.
   - "destructive operation" 확인 창이 뜨면 **Run this query**를 누르세요(같은 이름의 규칙을 지우고 다시 만드는 줄 때문이며, 기존 앱 기록은 지우지 않습니다).

이걸 하기 전에는 앱 오른쪽 위에 "이 기기에만 저장"이 보이고, 글은 그 태블릿에만 남습니다.

### 2. 제미나이 키와 중계 함수 (2번 단계에서 안내)

### 3. GitHub Pages 켜기

1. GitHub 저장소 화면에서 **Settings** → 왼쪽 **Pages**를 누릅니다.
2. **Source**를 "Deploy from a branch", **Branch**를 `main`, 폴더를 `/ (root)`로 고르고 **Save**를 누릅니다.
3. 1~2분 뒤 위의 학생용 주소가 열립니다.
   - 무료 GitHub 계정에서는 저장소가 **Public**이어야 Pages를 켤 수 있습니다.

## 알아 두실 점

- 기록과 사진은 링크를 아는 누구나 볼 수 있는 수업용 설정입니다. "쓴 사람만 보기"(질문 초안)도 화면에서 가리는 정도이지 완전한 잠금은 아닙니다.
- Supabase 무료 요금제는 1주일 동안 아무도 쓰지 않으면 멈춥니다. 수업 전날 한 번 열어 오른쪽 위 점이 초록인지 확인하세요.
- 앱을 고친 뒤 태블릿에 옛 화면이 남아 있으면 파일 주소 끝의 `?v=숫자`를 하나 올립니다(Claude가 해 드립니다).
