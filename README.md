# 경북 자원 지도

4학년 사회 공개수업(2026-10-21)에서 아이들이 경북 22개 시군의 자원을 조사해 지도에 올리고, 자원끼리 화살표로 잇고, TAG 피드백과 AI 챗봇(제미나이)으로 일반화 문장을 쓰는 웹앱입니다.

- 학생용 주소: https://jcteacher7.github.io/gyeongbuk-resource-map/
- 이 저장소는 공개입니다. 아이들 실명과 비밀 키는 넣지 않습니다.

## 지금 되는 것

**들어가기**: 모둠 → 이름 고르기. 학생용 주소는 늘 이 처음 화면으로 열립니다.

**우리 지도** (수업 전: 반 전체가 함께 만드는 자원 지도)
- 정확한 경북 22개 시군 지도, [+] [−] [처음 크기], "크게 보기", 한 손가락으로 밀어 옮기기
- 모둠마다 맡은 시군에 자원 카드를 올립니다: 환경(자연/인문)과 이유 → 자원 이름과 많아요/적어요 → 링크와 사진 한 장
- 모든 모둠의 자원이 한 지도에 모입니다. 고치기는 같은 모둠 누구나, 지우기는 올린 사람만(선생님은 모두)

**교류 제안서** (선생님이 열면 쓸 수 있음. 자원 지도를 다 만든 뒤)
- 완성된 자원 지도 위에서 모둠이 **제안 지역 하나**를 정합니다(지도에서 시군을 누르고 [제안 지역으로 정하기])
- [화살표 잇기] → 출발 자원 → 도착 자원 → 교류 방식, 생활 변화 두 줄. 화살표 한쪽은 제안 지역의 자원이어야 합니다
- 화살표를 누르면 두 자원 사진과 "환경 → 교류 → 생활 변화" 세 걸음이 팝업으로 열립니다
- 화살표는 모둠별로 따로 보입니다. 위쪽의 모둠 단추로 다른 모둠의 제안서를 볼 수 있습니다(발표 때 청중이 사용)

**TAG** (선생님이 열면 쓸 수 있음)
- 발표 모둠을 고르고 질문 초안(나만 봄)을 적어 둔 뒤, 발표를 듣고 T·A·G를 한 줄씩 남깁니다
- 초안은 [질문(A)로 옮기기]로 A 칸에 옮겨 고쳐서 남길 수 있습니다
- 발표 모둠은 [우리 모둠이 받은 TAG]에서 받은 TAG를 T·A·G 칸으로 나눠 봅니다

**AI 챗봇** (선생님이 열면 쓸 수 있음)
- 모둠당 태블릿 한 대로 씁니다. 모둠이 함께 고민해 대답합니다. 단계: 대조 상황 → 반대 추론 → 실제 사례 비교 → 모둠 문장 완성
- 단계는 **선생님이 반 전체를 한꺼번에** 넘깁니다(선생님 화면 → 챗봇 한눈에 → [다음 단계 열기]). 아이 화면에는 넘기는 단추가 없습니다
- 모둠 대답이 단계 기준을 채우면 AI가 판정해 "미션 성공!"과 별이 뜹니다
- AI가 느리면 "AI가 생각 중이에요", 실패하면 [다시 보내기]가 나오고 아이가 쓴 말은 지워지지 않습니다
- 4단계에서 문장 틀의 빈칸을 채워 [모둠 문장 저장]

**선생님 화면**: 들어가기 화면의 **제목(경상북도 자원 지도)을 3초 안에 다섯 번** 누르면 암호 칸이 나옵니다. 처음 한 번은 네 자리 암호를 정합니다.
- 위쪽: 교류 제안서, TAG, AI 챗봇 화면 열기/닫기, [지도 보기](선생님으로 지도에 들어가 모두 고치고 지울 수 있음), [나가기]
- 현황: 모둠별·아이별 자원·화살표·TAG·챗봇 수(0은 빨갛게), 지도에 아직 안 올린 아이, 시군별 수
- TAG: 발표 모둠별로 T·A·G 모아 보기, 지우기
- 챗봇 한눈에: 모둠 4개의 대답을 단계별로 한 화면에(전자칠판용 [크게 띄우기]), 미션 성공 표시, [다음 단계 열기]
- 챗봇 기록: 모둠별·아이별로 아이 말과 AI 답, 시각
- 모둠 문장: 모둠 문장 4개를 한 화면에, [크게 띄우기]로 교실 앞 화면에 띄우기
- 설정: 명단과 모둠, 시군 배정, 화면 이름, T·A·G 이름과 안내·글자 수, 챗봇 안내·단계 이름·첫 질문·문장 틀, 암호 바꾸기
- 지우기: 지도(사진 포함), TAG, 챗봇 기록, 모둠 문장, 명단, 수업 끝(전부)

## 선생님이 직접 해야 하는 일

### 1. Supabase에 저장 공간 만들기 — 끝남(2026-10-05)

다시 만들어야 할 때만: Supabase의 `wigxlmwysuqxiuonucqq` 프로젝트 → **SQL Editor** → **+** → `supabase/schema.sql` 내용을 붙여넣고 **Run**.

### 2. 제미나이 키 만들기 (수업 전용 새 키) — 끝남(2026-10-10)

1. https://aistudio.google.com 에 학교 수업용 구글 계정으로 로그인합니다.
2. 왼쪽 아래(또는 위) **Get API key** → **Create API key**를 누릅니다.
3. 만들어진 키(`AIza…`로 시작)를 **복사만** 해 둡니다. 이 키는 채팅, 파일, 저장소 어디에도 붙여넣지 마세요. 아래 3번의 Supabase 비밀 값 칸에만 넣습니다.
4. 지금은 **무료 등급**으로 씁니다(결제 연결 안 함). 한도는 AI Studio → **Dashboard → Rate limit**에서 봅니다.
   - 2026-10-10 기준: 가벼운 모델 둘을 합쳐 1분에 30번쯤, 하루 1,000번. 수업 예상(200~300번)에는 충분합니다.
   - 1분 한도를 잠깐 넘으면 앱이 "AI가 생각 중이에요"를 보여 준 채 몇 초 뒤 저절로 다시 보냅니다.
   - **수업 당일에는 미리 시험을 많이 하지 마세요.** 하루 한도를 수업 전에 쓰게 됩니다.

### 3. 챗봇 중계 함수 만들기 (Supabase) — 끝남(2026-10-10)

함수 코드를 고쳤을 때만 다시 합니다: **Edge Functions → gemini-chat → Code** 탭 → 전체 지우고 새 내용 붙여넣기 → **Deploy updates**.

1. https://supabase.com/dashboard/project/wigxlmwysuqxiuonucqq 로 들어갑니다.
2. 왼쪽 메뉴 **Edge Functions** → **Secrets**(비밀 값)를 누릅니다.
   - **Name**: `GEMINI_API_KEY`, **Value**: 2번에서 복사한 키 → **Save**
3. 다시 **Edge Functions** → **Deploy a new function** → **Via Editor**를 누릅니다.
4. 함수 이름을 `gemini-chat`으로 정합니다(꼭 이 이름).
5. 편집 칸의 기본 내용을 모두 지우고, 이 저장소의 `supabase/functions/gemini-chat/index.ts` 내용을 전부 붙여넣고 **Deploy function**을 누릅니다.
6. 만들어진 함수 화면에서 **Details**(또는 Settings) → **Verify JWT with legacy secret**(JWT 확인)을 **끄고** 저장합니다.
   - 이 앱은 새 방식 공개 키를 써서, 이걸 켜 두면 챗봇이 "AI가 대답하지 못했어요"만 보여 줍니다. 대신 함수가 직접 명단·글 길이·보내는 횟수를 확인합니다.
7. 끝나면 Claude에게 "함수 만들었어"라고 알려 주세요. 시험해 드립니다.

함수가 막는 것: 한 번에 200자 넘는 글, 한 사람이 1분에 6번·하루 80번 넘게 보내기, 반 전체 하루 1500번 넘게 보내기, 명단에 없는 이름, 선생님이 챗봇 화면을 닫았을 때.

### 4. GitHub Pages 켜기 — 끝남(2026-10-05)

### 5. 앱이 완성되면: 선생님 화면 → 설정에서 명단, 모둠, 시군 배정 입력

### 6. 수업 뒤 정리

1. 선생님 화면 → **지우기** → **수업 끝: 위 기록 전부** (사진, 기록, 명단까지 지움)
2. https://aistudio.google.com 의 **API keys**에서 수업 전용 키를 **Delete**
3. Supabase → Edge Functions → Secrets에서 `GEMINI_API_KEY` 지우기

## 알아 두실 점

- 기록과 사진은 링크를 아는 누구나 볼 수 있는 수업용 설정입니다. 질문 초안(나만 봄)과 선생님 암호도 화면에서 가리는 정도이지 완전한 잠금은 아닙니다.
- Supabase 무료 요금제는 1주일 동안 아무도 쓰지 않으면 멈춥니다. 수업 전날 한 번 열어 오른쪽 위 점이 초록인지 확인하세요.
- 앱을 고친 뒤 태블릿에 옛 화면이 남아 있으면 파일 주소 끝의 `?v=숫자`를 하나 올립니다(Claude가 해 드립니다).
