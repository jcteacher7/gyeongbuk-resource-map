# 경북 자원 지도 웹앱 스케치 (확정)

2026-10-05에 선생님과 Claude 채팅에서 정하고 "확정"을 받은 내용입니다. 확정된 것은 다시 묻지 말고 만듭니다. 원본은 Claude Docs 문서이며, 이 파일은 그 전문을 옮긴 것입니다.

## 목적과 수업 순간

10월 21일(수) 사회 공개수업에서, 아이들이 경북 22개 시군의 자원을 조사해 지도에 올리고 연결하며 "공간과 시간에 따라 자원의 희소성이 발생하고, 이에 따라 사람들의 생활 모습이 변한다"를 스스로 이해하게 하는 앱입니다.

- 수업: 4학년 1반 18명, 4-1 교실, 40분 (생각 열기 5분, 발표하기 15분, 일반화 재진술 15분, 성찰 5분)
- 수업 전 약 이틀(날짜 미정, 선생님이 알아서 정함): 아이들이 지도에 자원을 올리고 화살표로 잇습니다.
- 수업 날 발표하기: 청중이 질문(A) 초안과 TAG 피드백을 앱에 남깁니다.
- 수업 날 일반화 재진술: 모둠이 AI 챗봇(제미나이)과 "만약에 ~라면?" 대화를 하고 모둠 일반화 문장을 씁니다.
- 성찰은 이미 따로 만든 앱(저장소 mungyeong-AI-project-tool 안의 reflect)을 쓰므로 이 앱에는 넣지 않습니다.

## 사용자와 기기

18명이 한 명당 태블릿 한 대(갤럭시탭, 가로 화면)로 씁니다. 로그인은 없고, 모둠을 누른 뒤 자기 이름을 눌러 들어옵니다.

- 모둠 4개: 4명, 4명, 5명, 5명
- 명단은 앱이 완성된 뒤 선생님이 선생님 화면에서 입력합니다. 이름을 직접 치는 칸은 없고, 실명은 코드에 넣지 않습니다. 코드는 GitHub에 올라가 누구나 볼 수 있기 때문입니다.
- 글은 사람마다 칸이 따로 저장되고 댓글처럼 쌓입니다. 여럿이 동시에 써도 서로의 글이 지워지지 않습니다.
- 학생용 주소는 늘 처음 화면(모둠 고르기)으로 열립니다. 앞사람 이름으로 들어가 있는 일을 막기 위해서입니다.

## 화면 흐름

아이들 화면 4개, 선생님 화면 1개입니다.

1. **들어가기**: 모둠과 이름을 골라서 들어갑니다.
2. **우리 지도**: 시군 지도에 자원 카드와 화살표·이유를 올리고 봅니다.
3. **TAG**: T·A·G를 한 줄씩 댓글처럼 남깁니다.
4. **AI 챗봇**: "만약에 ~라면?" 질문을 하며 모둠 일반화 문장을 완성합니다.

**선생님 화면**: 네 화면을 모두 보고 고칠 수 있고, TAG와 챗봇은 선생님이 열고 닫습니다.

아이들은 1번에서 시작해 2, 3, 4번 순서로 움직입니다.

## 지도와 입력 방식

지도는 경북 22개 시군(10시 12군)을 눌러서 고르는 구역으로 나눈 정확한 경북 지도입니다. 아이들은 이 지도 위에서 자원을 올리고 자원끼리 화살표로 잇습니다.

### 지도

- 22개 시군이 각각 구역입니다. 처음엔 구역 안에 작은 이름만 두고, 조사 자료가 올라온 시군에만 알약 모양 핀이 뜹니다.
- 확대는 [+] [−] [처음 크기] 단추와 "이 시군 크게 보기"로 합니다. 두 손가락 확대는 쓰지 않습니다. 지도를 미는 동작과 화살표를 긋는 동작이 부딪치기 때문입니다.
- 지도 모양 자료는 Claude Code에서 구하고, 출처와 이용 조건을 먼저 확인합니다. 군위군은 2023년에 대구로 편입되어 지금 경북은 22개 시군이므로, 자료에 군위가 들어 있지 않은지 확인합니다. (docs/map-data.md 참고)
- 아이들이 맡을 시군은 선생님 화면에서 모둠별로 정하고 나중에 바꿀 수 있습니다. 기록은 시군마다 붙는 고정 번호에 저장되어 배정을 바꿔도 사라지지 않습니다.

### 자원 올리기

지도에서 시군을 눌러 시작합니다. 모든 칸은 한 줄이고 40자 안팎으로 제한합니다. 시군 하나에 자원은 3개 정도를 기준으로 합니다.

1. 이 자원은 어떤 환경 때문에 있나요? 자연환경 / 인문환경 중 하나를 고르고 이유를 한 줄로 씁니다.
2. 자원 이름을 쓰고, 이 시군에 많아요 / 적어요 중 하나를 고릅니다.
3. 링크와 사진 한 장을 넣습니다.

### 화살표 잇기

자원에서 자원으로 잇습니다.

1. [화살표 잇기] 단추를 누른 뒤 두 자원을 차례로 누릅니다. 손가락으로 긋지 않습니다.
2. 어떻게 교류하나요? 한 줄, 그러면 생활 모습이 어떻게 달라지나요? 한 줄을 씁니다.
3. 팝업에는 두 자원의 사진이 붙고, "환경 → 교류 → 생활 변화"가 세 걸음으로 이어져 보입니다. 지도에서는 두 시군 사이의 화살표로 보이고, 누른 화살표만 굵게 강조됩니다.

### 고치기와 지우기

같은 모둠은 누구나 항목을 고칠 수 있고, 지우기는 올린 사람만 합니다. 모든 항목에 올린 사람 이름이 붙습니다. 선생님은 선생님 화면에서 모두 지울 수 있습니다.

## 저장되는 것

저장은 늘 쓰시던 Supabase와 GitHub Pages로 하고, GitHub 저장소는 이 앱용으로 새로 만듭니다(gyeongbuk-resource-map). 기록은 선생님이 선생님 화면에서 지울 때까지 보관합니다.

| 저장되는 것 | 누가 쓰나 | 누가 읽나 |
|---|---|---|
| 자원 카드: 환경 구분과 이유, 자원 이름, 많아요/적어요, 링크, 사진 | 모둠원 | 모두 |
| 화살표와 이유 두 줄(교류 방식, 생활 변화) | 모둠원 | 모두 |
| TAG 피드백과 질문(A). 초안은 쓴 사람만 봄 | 청중 아이 | 발표 모둠과 선생님 |
| 챗봇 대화: 아이 말과 AI 답을 한 쌍으로, 모둠·이름·시각과 함께 | 모둠 | 선생님과 모둠 |
| 모둠 일반화 문장: 완성된 문장 그대로 | 모둠 | 선생님과 모둠 |

- 사진은 Supabase의 파일 저장 장치(Storage)에 올립니다. 올릴 때 앱이 자동으로 작게 줄이고(긴 쪽 1280px 안팎, 한 장 200~300KB), 지도 목록에서는 작은 미리보기만 불러옵니다. 최대 66장(22개 시군 × 3개)은 무료 요금제 한도 안입니다.
- 무료 요금제는 파일 저장 1GB, 월 전송량 5GB이고, 1주일 동안 아무도 쓰지 않으면 프로젝트가 일시 정지됩니다. 2026년 10월 5일에 Supabase 요금제 페이지(https://supabase.com/pricing)에서 확인한 내용입니다. 수업 전날 한 번 열어 저장이 되는지 확인합니다.
- 사진과 기록은 링크를 아는 누구나 볼 수 있는 수업용 설정이 됩니다. 올리는 화면에 "얼굴이 나온 사진은 올리지 않아요" 안내를 넣고, 끝난 뒤 선생님 화면에서 지우는 방법을 같이 둡니다.
- AI 챗봇(제미나이) 키는 앱 안에 심지 않습니다. 서버 쪽 비밀 보관함에 넣고 작은 중계 장치로 부르며, 아이들은 키 없이 챗봇을 씁니다. 키는 이 수업 전용으로 새로 발급해 수업 뒤에 지웁니다.
- 비밀 키는 코드와 GitHub 어디에도 넣지 않습니다. 공개 키는 기존 앱(mungyeong-AI-project-tool)의 설정을 확인해 같은 방식으로 붙입니다.

## 선생님 기능

선생님 화면은 단추를 감추고 숨은 입구와 네 자리 암호로 가립니다. 아이들이 우연히 들어가는 것을 막는 정도이고 완전한 잠금은 아닙니다. 참관자가 오는 날이므로 이 점을 알고 계셔야 합니다.

### 보기

- 모둠별·시군별 입력 현황: 자원과 화살표가 몇 개 올라왔는지, 입력 기간에 아직 안 한 아이가 누구인지
- 쌓이는 TAG 전체
- 챗봇 대화 기록: 아이가 보낸 말과 AI의 답, 모둠별·아이별로 봅니다.
- 모둠 일반화 문장 4개를 한 화면에: 교실 앞에 띄워 학급 문장을 합의할 때 씁니다.

### 직접 고치기

- 명단과 모둠 구성 (지도 입력을 시작하기 전에 확정)
- 아이들이 맡을 시군 배정
- 일반화 문장 틀, 화면 이름과 챗봇 단계 이름, 챗봇 질문과 안내 문구
- T·A·G에 붙는 이름과 입력칸 안내 문구, 한 줄 글자 수

### 단계 열고 닫기

지도 입력 기간에는 TAG와 챗봇 화면을 닫아 두고, 수업 날 선생님이 단추로 하나씩 엽니다. 아이들이 미리 들어가 눌러 보는 일을 막고 수업 흐름도 선생님이 쥐기 위해서입니다. 이 밖에 필요한 기능은 앱을 써 본 뒤 추가합니다.

## 막아야 할 실수

공개수업에서는 참관자가 보고 있고, 교실 와이파이에 태블릿 18대가 붙습니다. 아래 상황은 처음부터 설계에 넣습니다.

| 일어날 수 있는 일 | 이렇게 막습니다 |
|---|---|
| 한글을 치는 도중 화면이 다시 그려져 글이 깨지거나 사라짐 | 입력 중이거나 글자를 조합하는 중에는 화면을 다시 그리지 않습니다. |
| 저장됐는지 아이가 모름 | 저장 단추를 눈에 띄게 두고, 못 누를 때는 이유를 적습니다(예: "이름을 먼저 골라 주세요"). 저장하면 "남겼어요"가 보입니다. |
| 인터넷이 끊김 | "아직 서버에 못 보냈어요, 이 태블릿에만 있어요"를 보여 주고, 연결이 돌아오면 다시 보냅니다. |
| 새로고침하거나 태블릿이 꺼졌다 켜짐 | 쓰던 글은 서버에 남아 있어 이어서 쓸 수 있습니다. |
| 여럿이 같은 칸에 동시에 입력 | TAG는 사람마다 칸이 따로입니다. 지도 항목은 같은 모둠 누구나 고치되 지우기는 올린 사람만 합니다. |
| 챗봇이 느리거나 실패함 | "AI가 생각 중이에요"를 보여 주고, 실패하면 "다시 물어봐 주세요"와 다시 보내기 단추를 둡니다. 아이가 쓴 말은 지워지지 않습니다. |
| 다음 사람이 앞사람 이름으로 들어가 있음 | 학생용 주소는 늘 처음 화면(모둠 고르기)으로 열립니다. |
| 지도를 밀려다 화살표가 그어짐 | 화살표는 긋지 않고, 단추를 누른 뒤 두 자원을 차례로 누릅니다. |
| 면적이 작은 시군을 누르기 어려움 | [+] [−] [처음 크기] 단추와 "이 시군 크게 보기"를 둡니다. |
| 사진에 아이 얼굴이 나옴 | 올리는 화면에 "얼굴이 나온 사진은 올리지 않아요" 안내를 넣습니다. |

## 바뀔 것과 고정할 것

수업 전에 써 보며 바꿀 것은 선생님 화면에서 고치고, 바뀌면 안 되는 것은 코드에 고정합니다.

### 선생님 화면에서 고치는 것

- 명단과 모둠 구성
- 아이들이 맡을 시군 배정
- 일반화 문장 틀(빈칸 위치와 문구)
- 화면 이름과 챗봇 단계 이름
- 챗봇 질문과 안내 문구
- T·A·G에 붙는 이름과 입력칸 안내 문구, 한 줄 글자 수
- TAG와 챗봇을 열고 닫는 단추

### 코드에 고정하는 것

- 화면 4개의 순서: 들어가기, 우리 지도, TAG, AI 챗봇
- T·A·G 세 가지로 나뉘는 구조(이름은 바꿔도 칸은 세 개)
- 챗봇이 거치는 순서: 대조 상황, 반대 추론, 실제 사례 비교, 모둠 문장 완성
- 자원 카드와 화살표 이유의 입력 순서: 환경, 자원, 교류 방식, 생활 변화

아이가 완성한 일반화 문장은 빈칸 값이 아니라 완성된 글 그대로 저장합니다. 문장 틀을 나중에 고쳐도 이미 쓴 문장은 그대로 읽힙니다. 이름과 문구를 바꾸는 것은 언제든 안전하지만, 빈칸 개수를 바꾸는 것은 아이들이 쓰기 전에 합니다.

## 느낌

보여 드린 시안 세 가지 중에서 **가의 색과 모양**에 **다의 글씨체**를 합칩니다. (시안 파일은 design/ 폴더)

- **색과 모양**: 연한 민트색 바탕, 하늘색 바다, 노란 땅, 산호색 강조, 짙은 남색 글자. 관광 안내도처럼 둥글고 귀여운 모양.
- **글씨체**: 손글씨 느낌의 개구(Gaegu) 굵은 글씨. 작은 안내 글자는 또렷하게 읽히는 글꼴을 따로 씁니다.
- **움직임은 꼭 필요한 곳에만**: 화살표 위로 점선이 흐르고, 새 화살표의 이유 딱지가 통통 튀고, 팝업이 톡 하고 열립니다. 글을 쓰는 화면(TAG, 챗봇)에는 움직임을 거의 넣지 않습니다.
- 기기 설정에서 **움직임 줄이기**를 켜 두었으면 움직임을 끕니다.
- 화면 크기는 태블릿 가로(1280×800)를 기준으로 맞춥니다.

시안의 지역 4곳과 이름(홍길동)은 모양을 보여 드리려고 넣은 자리 표시입니다. 실제 앱은 22개 시군의 정확한 경북 지도 모양입니다.

## 성공 기준

공개수업 날 이 앱이 잘 만들어졌다고 말할 수 있는 모습입니다.

- 22개 시군마다 자원 카드가 올라와 있고, 사진과 조사한 내용, 링크가 열립니다.
- 아이들이 만든 화살표와 이유가 팝업으로 잘 열립니다.
- 수업 날 18명이 모두 TAG를 남깁니다.
- 4개 모둠의 일반화 문장이 저장되어 있습니다.
- 챗봇에 아이들이 쓴 질문(프롬프트)과 AI 답이 모둠·이름·시각과 함께 남아 있습니다.
- 수업 중에 앱이 멈추거나 글이 사라지지 않습니다.

## 만드는 순서와 확인할 것

### 만드는 순서

1. **지도**: 정확한 22개 시군 지도, 확대·축소, 자원 카드(사진 포함), 화살표와 이유

지도 입력은 공개수업(10월 21일) 이틀 전쯤 아이들이 하므로, 1번은 그 전에 끝나 있어야 합니다. 2번과 3번은 수업 전까지 끝냅니다. 지도 입력을 시작할 날짜는 선생님이 알아서 정합니다.
