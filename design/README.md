# 느낌 시안

선생님께 보여 드린 "귀여운 관광 지도" 시안 3개입니다. 확정된 것은 **가의 색과 모양 + 다의 글씨체(Gaegu 굵게)**입니다.

| 파일 | 이름 | 비고 |
|---|---|---|
| `Main.dc.html` | 가. 관광 안내도 | 확정: 색과 모양 |
| `Sticker.dc.html` | 나. 스티커 지도 | 쓰지 않음 |
| `Notebook.dc.html` | 다. 여행 수첩 | 확정: 글씨체(Gaegu 굵게) |
| `canvas.json` | 시안 배치 정보 | |

- 이 파일들은 Claude의 디자인 캔버스용 파일(`.dc.html`, 1280×800 판)이라 브라우저로 바로 열면 제대로 안 보일 수 있습니다. HTML과 CSS를 읽어서 색, 모양, 움직임을 가져다 쓰세요.
- 안에 든 지역 4곳, 자원 카드 4개, 이름 "홍길동"은 모양을 보여 주려는 **자리 표시**입니다. 실제 앱은 22개 시군의 정확한 경북 지도입니다.
- 가 시안에서 가져올 값
  - 바탕 `#E6F5F2`(연한 민트), 바다 `#BDE5EC`, 땅 `#F8E9A9`, 강조 산호색 `#FF6B57` / 진한 `#C93A27`, 글자 짙은 남색 `#1E3A4C`
  - 알약 핀(둥근 모서리), 화살표 `Q` 곡선 + 점선이 흐르는 움직임, 선택한 화살표 위의 이유 딱지가 통통 튀는 움직임, 팝업이 톡 열리는 움직임
  - 움직임 줄이기 설정을 켜면 움직임을 끈다
- 글꼴: 큰 글씨는 Gaegu 굵게(Google Fonts), 작은 안내 글자는 또렷한 글꼴(시안의 Gowun Dodum 등)을 쓴다.
- 화면 크기 기준은 1280×800(16:10)입니다.
